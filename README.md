# Fausto Jiménez — Plataforma de marca personal

Experiencia digital de marca personal para Fausto Jiménez: estratega digital, consultor de innovación e instructor de IA.

Ver `BRAND.md` (marca y design tokens), `SITEMAP.md` (arquitectura del sitio) y `prisma/schema.prisma` (modelo de datos) para el detalle del diseño.

## Stack
- Next.js (App Router) + TypeScript + TailwindCSS
- shadcn/ui, Framer Motion, GSAP, Lenis
- next-intl (ES/EN)
- Prisma + Postgres, Auth.js, Stripe

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).
